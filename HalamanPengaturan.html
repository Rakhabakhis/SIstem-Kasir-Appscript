⚠️ Otorisasi MailApp Belum Diberikan
Untuk mengaktifkan notifikasi email, jalankan dari Apps Script Editor:
  1. Buka Extensions → Apps Script
  2. Pilih fungsi dapatkanUrlOtorisasi dari dropdown
  3. Klik ▶ Run → salin URL dari Log Eksekusi
  4. Buka URL di browser → klik Allow / Izinkan
  5. Jalankan inisialisasiMailApp untuk verifikasi
